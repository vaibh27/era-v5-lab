## What the numbers show

- Qwen solves 6 to 8 times as many cells as OLMoE at every label (39 to 42 of 110 against 5 to 7).
- The 1024 cap dominates the code arm. 195 of 240 code cells hit the cap, and 166 code cells fail with "no code
  block": Qwen explains its approach first and is cut off before the code. The suite sends no answer-format
  instruction, so this is the model's default style meeting the cap, not a checker fault. Code success here is a
  floor, not Qwen's ability (the attainability survey saw the same truncation; see PR #60 for the 2048 re-run).
- Math is far less affected: median 600 tokens, 67 of 200 cells censored, and 17 censored cells still count as
  correct because the boxed answer came before the cut.
- The label does nothing visible at a fixed cap, as with OLMoE. Correct counts move 39 / 42 / 39 / 41, and against
  1k the matched cells move +8/-5 (4k), +5/-5 (16k) and +7/-5 (64k). That is noise at k=2.
- "parse ok" is trivial here too: Qwen writes plain text with no G10 markers, so every cell parses.
