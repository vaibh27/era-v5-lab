# Build: sheets to `clean.py`

Paths and commands start at the repository root. Install [../requirements.txt](../requirements.txt) before running data-dependent tools. [The cleaner guide](../README_clean.md) covers runner options; [shared tools](../../tools/README.md) and the [harm-test harness](../../harmtest/README.md) cover gold and contributor inputs. The scripts that check what the build produced are in [../validate](../validate/README.md).

| Purpose | Scripts | Inputs / outputs |
|---|---|---|
| Generate the cleaner | [build_clean.py](build_clean.py) | Reviewed `sheets/specv1.md` → `clean.py`; `--out` supports a temporary rebuild for comparison |
| Shared F1 rule | [f1_rule.py](f1_rule.py) | Pasted into `clean.py` by the builder; run last on the code, math, science and Indic packs |
| Integrate Indic and validated sibling scopes | [integrate_indic.py](integrate_indic.py), [extend_indic_siblings.py](extend_indic_siblings.py) | [Indic guide](../README_indic.md); native/receiving diagnosis packs and own-pack gold |

Runtime helpers that sit next to `clean.py` in [spec_v1/](../): [f2_rule.py](../f2_rule.py) (F2, opt-in through `run_clean.py --f2`) and [normalize.py](../normalize.py) (the word list shared with Team 09, which also has a version contract with them: do not edit it).

`clean.py` still says "GENERATED by spec_v1/tools/build_clean.py" in its header and in one comment. The builder writes those strings, a test compares `clean.py` byte for byte with a fresh build, and the tokenizer job pins its sha256. The paths are corrected at the next intentional rebuild.
